# lifetracker Docs

Welcome to the public Markdown docs shipped with the lifetracker web app.

These files are static documentation that can be opened directly from the site.
They are meant to be readable for users, admins, and developers without needing
the source repository UI.

## Guides

| Guide               | Link                                               | Best for                                                                |
| ------------------- | -------------------------------------------------- | ----------------------------------------------------------------------- |
| User Guide          | [user-guide.md](./user-guide.md)                   | People using habits, progress, challenges, language, and theme features |
| Admin Guide         | [admin-guide.md](./admin-guide.md)                 | Operators running the Docker stack or preparing production operations   |
| Developer Guide     | [developer-guide.md](./developer-guide.md)         | Engineers changing frontend, backend, shared packages, or docs          |
| Performance And SEO | [performance-and-seo.md](./performance-and-seo.md) | SEO, accessibility, web vitals, caching, and static docs checks         |

## Supported Languages

The app supports English, Russian, Spanish, German, French, and Serbian. It
detects the browser language on first visit and lets users change it manually.

## Theme

The app supports light and dark mode. The selected theme is saved in the
browser.
