# lifetracker User Guide

lifetracker helps you track habits, complete check-ins, join live challenges,
and see progress in real time.

## Sign In

Use the demo account:

```text
demo@lifetracker.dev / demo1234
```

You can also create a new account from the registration tab.

## Language And Theme

Supported languages:

- English
- Russian
- Spanish
- German
- French
- Serbian

The app detects your browser language on first visit. You can change language
and theme from the display preferences panel. Both choices are saved in the
browser.

## Dashboard

The dashboard shows:

- active streak;
- completed habits today;
- weekly completion rate;
- focus score;
- today's habits;
- weekly charts;
- live challenges;
- realtime activity feed.

On desktop, navigation is placed in the sidebar. On mobile, the layout stacks so
content and controls stay visible.

## Create And Complete Habits

To create a habit, enter a name, choose a category, pick a color, set the weekly
target, and press `Add habit`.

To complete a habit, choose a mood and press the check button on the habit row.
The dashboard updates progress and sends a realtime event.

## Challenges

Challenges are shared goals. Join a challenge from the dashboard to add it to
your activity and publish a realtime event.

## Friendly Errors

If something fails, lifetracker shows a localized message. Examples:

- wrong email or password;
- network problem;
- dashboard load failure;
- habit creation failure;
- challenge join failure;
- realtime connection issue.

When realtime is unavailable, saved dashboard data still works.
